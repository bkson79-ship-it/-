Firebase 연결 설정

이 파일은 Firebase 연결 정보가 있어야 여러 직원이 함께 사용할 수 있습니다. 아래 firebaseConfig 값을 본인 Firebase 프로젝트 값으로 교체한 뒤 사용하세요.

이 페이지 하단의 firebaseConfig 항목을 Firebase 콘솔의 웹 앱 설정값으로 교체하세요. 아직 연결 전이라면 먼저 Firebase 프로젝트와 Authentication, Firestore를 설정해야 합니다.
